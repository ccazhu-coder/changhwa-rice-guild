# AI Agent 招生頁｜Release Gate

> 適用範圍：AI Agent 產業應用實戰班招生頁、DM、廣告素材、課程頁與後續改版。
> 核心規則：未通過 Gate，不得標示為 Production，不得正式發布。

## 版本狀態
- DRAFT：內容未鎖定，不得對外。
- REVIEW：內容與視覺完成，待驗收。
- RC：Release Candidate，資料與功能已完成，待真機驗收。
- PRODUCTION：正式上線，且桌機與手機驗收完成。

## Gate 1｜資料鎖定
- [ ] 課程名稱正確
- [ ] 日期、時間、地點正確
- [ ] 講師姓名與經歷正確
- [ ] 價格、早鳥期限、會員補助正確
- [ ] 注意事項與自備設備正確
- [ ] 未出現未確認的名額、補助額度、折扣或承諾
- [ ] 報名／洽詢連結有明確下一步

## Gate 2｜素材治理
- [ ] LOGO 為正式原檔，禁止重繪、變形
- [ ] 講師照片為「本次指定最新照片」
- [ ] 歷史活動照片不得直接當本次招生主視覺
- [ ] 情境圖若非真實活動，不得暗示為本次課程實拍
- [ ] 所有圖片都有來源與用途紀錄
- [ ] 未核准素材不得進 Production

## Gate 3｜行銷與內容
- [ ] 第一屏 3 秒內知道：賣什麼、解決什麼、學完得到什麼
- [ ] 至少 3 個不同受眾／痛點鉤子
- [ ] 痛點不是整個產品定位，只是入口
- [ ] 成果與課程原始內容一致
- [ ] 不誇大、不虛構節省時間、成功率、名額、見證
- [ ] 6,800 元的價值理由清楚
- [ ] 適合／不適合對象清楚
- [ ] 前台無工程、測試、內部或後台字樣

## Gate 4｜UI／RWD
- [ ] Hero 是網頁思維，不是 DM／海報思維
- [ ] 桌機、平板、手機資訊層級正常
- [ ] 手機無橫向溢出
- [ ] sticky CTA 不遮擋內容
- [ ] 表格／輸入欄手機可操作
- [ ] 人像不裁臉、不變形
- [ ] 文字對比與字級符合可讀性
- [ ] CTA 視覺層級一致，橘色只作主要行動

## Gate 5｜功能 QA
- [ ] 適合度互動可勾選並更新
- [ ] 三種案例可切換
- [ ] 可修改資料
- [ ] 執行流程按鈕可用
- [ ] 結果會依輸入變化
- [ ] 重設可用
- [ ] 下載分析明細可用
- [ ] 複製摘要可用
- [ ] 頁面錨點跳轉可用
- [ ] 所有外部 CTA 可開啟正確目的地
- [ ] 電話連結可用
- [ ] LINE 連結可用

## Gate 6｜正式發布
- [ ] Chrome 桌機真機驗收
- [ ] iPhone Safari 真機驗收
- [ ] 正式網址 200 OK
- [ ] CSS／JS 正常載入
- [ ] SEO title／description／canonical 正確
- [ ] sitemap 有正式頁面
- [ ] 無舊素材快取誤用
- [ ] Git commit 可追溯
- [ ] 驗收人、日期、版本已記錄

## 一票否決條件
以下任一情況存在，不得稱為「正式版」：
1. 使用舊講師／舊活動照片且未經核准。
2. 報名 CTA 只回首頁或無法完成下一步。
3. 互動功能未測卻宣稱可用。
4. 手機未驗收。
5. 有未確認價格、補助、名額或不實成果。
6. 對外頁出現內部工程／測試字樣。
